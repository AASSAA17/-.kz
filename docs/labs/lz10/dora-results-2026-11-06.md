## Проверка инженерного конвейера

- [Успешный прогон CI с дополнительной проверкой утечек](https://github.com/AASSAA17/-.kz/actions/runs/42181416399): линтер, Node API-тесты, сборка Vite, OSV-Scanner, PostgreSQL 17, Gitleaks и публикация артефакта завершились успешно.
- Измерение `node --experimental-test-coverage` для загруженных серверных модулей `app.mjs`, `locations.mjs`, `storage.mjs`: **86,54 % покрытых строк**, **83,94 % ветвей**, **87,64 % функций**; проверено **22 теста** в наборе для покрытия. Это не показатель покрытия всего React-интерфейса и `server/index.mjs`.
- После замера добавлен обязательный порог **60 % покрытых строк** на Linux. Его прохождение проверяется в новых запусках CI.
- Контроль `main` через PR, обязательный review и статусы должен быть включён в GitHub Settings владельцем и проверен отрицательным тестом; один зелёный прогон не доказывает наличие защиты.
- CI публикует клиентский `dist/` как GitHub Actions artifact. Это **не означает**, что серверное приложение автоматически развёрнуто на Render.

## Часы на исправления и технический долг

На 06.11.2026 подтверждённого учёта часов, потраченных на устранение инцидентов после выпуска, нет. Поэтому записать `0 часов` или вычислить фактическую долю capacity нельзя. На следующих релизах фиксировать `deployment_id`, время обнаружения, время восстановления, часы исправления, владельца и ссылку на задачу; затем предложить резерв на надёжность по реальной доле затрат. Стартовый ориентир из лекции — 10–20 % capacity, **не фактическая оценка команды**.

## Как получить воспроизводимый снимок

```bash
python -m pip install -r docs/labs/lz10/requirements.txt
python scripts/dora_dashboard.py --from-utc 2026-09-25 --to-utc 2026-11-07 --out dora-output
```

Результат: `dora-output/dora-snapshot.json` и `dora-output/dora-dashboard.png`. [Workflow `dora.yml`](../../../.github/workflows/dora.yml) автоматически собирает и прикладывает их к запуску. Чтобы изменить дату или среду, необходимо явно указать параметры, иначе исторический снимок и новый измерительный период нельзя сравнивать.

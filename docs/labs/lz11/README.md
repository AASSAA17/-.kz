## Повторить проверку

1. В корне проекта выполните `npm ci`, `npm run lint`, `npm run build`, `npm test`. Для PostgreSQL задайте `TEST_DATABASE_URL` на отдельную тестовую базу. Для временной базы без TLS на loopback применяется `sslmode=disable` в режиме разработки.
2. Запустите приложение с отдельной базой SQLite на порту 3003. Используйте учебные данные. Откройте каталог и пройдите сценарии из PDF либо из формы в HTML.
3. Для k6 в Docker передайте в `LAB_DATE` будущую дату по Астане в формате ГГГГ-ММ-ДД. Из корня проекта в PowerShell можно выполнить команду ниже. На Docker Desktop адрес `host.docker.internal:3003` должен быть доступен из контейнера.

   ```powershell
   docker run --rm -e LAB_DATE=2026-11-15 -v "${PWD}/docs/labs/lz11:/lab:ro" grafana/k6 run /lab/load.js
   ```

4. В Uptime Kuma создайте HTTP-монитор на `http://host.docker.internal:3003/api/health` с интервалом 60 с и тайм-аутом 5 с. Для выполнения runbook нужны два последовательных сбоя и проверка с хоста и из контейнера.

Замер k6 относится к одному GET-методу на локальном стенде. Для Render и Neon нужен отдельный замер.

## Тақтаға көшіру тәртібі

Үш карточканы Issues-ке енгізу, Projects-ке қосу, owner мен due date-ті карточка сипаттамасында көрсету; тіркелген GitHub аккаунттары нақтыланған соң assignee орнату. To do → In progress → Review → Done. Done шарты: acceptance тесті, екінші адамның review-ы, дәлел сілтемесі. Қазір жергілікті тізім дайын болғанымен, әдістеменің «тақтада көрінеді» талабы әлі орындалмады.

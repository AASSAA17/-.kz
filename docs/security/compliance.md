# ЛЗ 7 Дербес деректер бойынша бастапқы чек парақ

Айтказинов Арсен және Ерденбаев Адильжан, АЖ-41. 16.10.2026. Бұл іске асырудағы олқылықтар тізімі; толық құқықтық сәйкестік туралы қорытынды емес.

| Сұрақ | Жоба фактісі | Жетіспейтін әрекет | Иесі |
|---|---|---|---|
| Қандай деректер | users: аты, тегі, email, телефон, пароль хеші/тұзы; bookings: аты, телефон, пікір; cookie мен verification хештері | Өрістер тізімін саясатқа енгізу; еркін пікірге сезімтал дерек жазбауды түсіндіру | Арсен |
| Мақсат | Аккаунтқа кіру, локацияға өтінім беру, мәртебесін өңдеу | Әр мақсатқа қажетті өрістерді ғана қалдыру | Арсен |
| Келісім | Формада checkbox, bookings.consent_at бар | Users келісім нұсқасы/уақыты бөлек сақталмайды; саясат пен кері қайтару тәртібі жоқ | Арсен |
| Қайда сақталады | Қазір осы ноутбуктағы PostgreSQL semka_kz; SQLite көшірмелері data ішінде | Ел/backup орны мен құрылғыға қолжетімділікті бекіту; localhost өзі елді дәлелдемейді | Адильжан |
| Кім көреді | API рөлі semka_app, DB әкімшісі; admin өтінімдердегі контактты көре алады | Қол жеткізетін адамдар тізімі мен жеке admin identity | Адильжан |
| Қанша уақыт | Қазір автоматты жою саясаты жоқ | Ұсыныс: демо дерек 30 күннен кейін жою, backup 7 күн; бұл заңдағы нақты мерзім емес, бекітілетін жорамал | Арсен |
| Аудит | Бронь мәртебесінің өзгерісі audit-те; аккаунт оқиғалары audit_events-те | Жеке админ атрибуциясы мен дерек оқу аудиті жоқ | Адильжан |
| Құпиялар | .env және data Git-тен шығарылған; пароль scrypt хеші | Gitleaks арқылы тарихты тексеру; табылған нақты секретті ауыстыру | Адильжан |
| Субъект сұрауы | Деректі қарау/жою үшін дайын рәсім жоқ | Контакт арнасын және сұрауды растау рәсімін бекіту | Арсен |
| Сыртқы сервис | Нақты SMS және Google қосылмаған; Neon/Render қазір қолданылмайды | Қоспас бұрын беру мақсаты, орналасуы мен шарттарын тексеру | Адильжан |
| ИИ компоненті | Қолданбада шешім қабылдайтын ИИ жоқ; Codex әзірлеуде қолданылды | Өнімге ИИ қосылса, бөлек дерек ағыны мен тәуекел талдауы қажет | Арсен |
| ЖОО саясаты | Ішкі ереже берілмеген | Оқытушыдан құжатты алып, талаптармен салыстыру | Арсен |

Нормативтік тексерудің негізі: ҚР «Дербес деректер және оларды қорғау туралы» заңының 7–8 баптарындағы келісім тәртібі және 12-баптағы жинақтау/сақтау талаптары қаралады. 12-бап деректерді Қазақстан аумағындағы база/цифрлық объектіде сақтау талабын және мақсатқа байланысты мерзімді сипаттайды. Сондықтан шетелдік хостингті тегін болғаны үшін автоматты түрде жарамды деп есептеуге болмайды. Жобада бұл талаптарды орындау дәлелі мен ЖОО келісімі әлі жиналуы тиіс.

Ресми дереккөз: [Әділет Заң №94-V](https://old.adilet.zan.kz/rus/docs/Z1300000094), қаралған күні 16.10.2026. Нақты қолданылатын редакция мен күшіне ену күндері тапсыру алдында қайта тексеріледі.

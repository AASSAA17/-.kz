## Pre-mortem үшін талқылау

«Семестр соңында Съёмка.kz көрсетілімі сәтсіз өтті: не болды?» Арсен интерфейс, формалар, мобильді экран, талаптар мен тапсырыс беруші байланысын жеке қарастырады. Адильжан база, пароль, броньдау жарысы, backup, интеграция және серверді қарастырады. Әрқайсысы 25 минут жеке жазады, кейін ұқсас себептер біріктіріледі. Бұл рәсім орындалған деп есепте белгілеуге әлі болмайды.

## Нақты талдау нәтижесі

Оқшауланған SQLite тестінде user login-нің жеті қате сұрауы да 401 берді, бірақ auth_rate_limits кестесінде 0 жазба қалды. Verify кодының қате әрекеттері де сақталмады. Себебі throw арқылы transaction-нан шығу санағыш өзгерісін rollback жасайды. Бұл әкімшінің ескі login лимитімен бірдей код емес: admin тестінің өтуі user login қауіпсіздігін дәлелдемейді. SEC-01 осы ақауға арналған.

Сайт PostgreSQL-ге қосылған; қосарланған броньдан қорғаныстың жеке PostgreSQL тесттері бұрын өткен. Бұл бүкіл авторизация толық қауіпсіз дегенді білдірмейді. Нақты SMS жеткізуі мен Google OAuth бапталмаған. Модель тек бар броньдау ағыны мен қазіргі іске асыруға сүйенеді.

## Әрі қарай орындалатын қадамдар

1. Екі адамның pre-mortem нәтижесін біріктіріп, P және сағат бағасын бекіту.
2. SEC-01 және SEC-02 іске асыру, регрессиялық тесттермен растау.
3. Сканерлерді іске қосу; табылған нәтижелерді RAID немесе backlog-қа енгізу.
4. Модельді Threat Dragon-ға түсіріп, өңделетін JSON және сурет экспорттау.
5. ЖОО ережесін алу, келісім мен retention шешімін бекіту.
6. SEC-01–03 карточкаларын GitHub Projects-ке енгізіп, сілтемелерін есепке жазу.

ИИ қолданылуы: Codex кодты талдау, бастапқы тәуекелдер мен құжат мәтінін дайындау үшін қолданылды. Арсен мен Адильжан бағаларды және қорытындыларды тексеріп бекітеді. Жұмыс әлі «толық тапсырылды» мәртебесінде емес.

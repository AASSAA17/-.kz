# Фотографии демонстрационных локаций

Фотографии служат иллюстрациями для вымышленных карточек MVP. Они не подтверждают существование студий по указанным в демонстрационных данных параметрам и не означают сотрудничество с авторами или владельцами изображённых помещений. Перед настоящим запуском замените их фотографиями партнёрских площадок с разрешением на использование.

Все фотографии получены с Pexels и используются в интерфейсе сайта по [лицензии Pexels](https://www.pexels.com/license/). Проверено 25 сентября 2026 года. Авторы сохраняют свои права; лицензия кода проекта на фотографии не распространяется.

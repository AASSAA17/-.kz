# Новый дизайн главной страницы

16.10.2026. Реализован выбранный пользователем макет public/design-preview.html.

Главная использует большое локальное фото garden.jpg, светлый каталог, зелёные фильтры и оранжевую кнопку поиска. Карточки показывают все пять существующих локаций и их локальные jpg. Общие формы бронирования, admin и авторизация сохранены; панели оформлены в той же палитре.

Вместо неподключённого поля «формат съёмки» в предварительном макете реализовано поле «длительность»: это параметр реального API. При выборе даты главная проверяет availability всех локаций и оставляет те, где есть хотя бы один свободный интервал подходящей длины. Точное начало выбирается в карточке. Дата и длительность передаются через query string. Без даты показывается каталог по типу. Пустой результат, ошибка API, загрузка и сброс поиска обработаны.

Проверено в headless Edge через Playwright: пять карточек, фильтр лофт, сброс типа, поиск по дате/двум часам, передача даты в карточку, формы /login, /register, /admin; ошибок pageerror нет. Проверен viewport 1440×1000 и 390×844, горизонтального переполнения нет. Снимки сохранены локально в work/design-desktop.png и work/design-mobile.png и визуально просмотрены. Скриншоты не являются тестом реальной SMS или авторизации Google.

Данные PostgreSQL и API броньования не менялись в ходе редизайна. Бронь при выборе слота повторно проверяет конфликт на сервере: результат поиска на главной не резервирует время.

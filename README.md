# Съёмка.kz

Платформа бронирования локаций и съёмочной команды (фото/видео) в Астане.

## О проекте
Каталог из 5 локаций студии + опциональная съёмочная команда
(фотограф/видеограф/мобилограф), бронирование с пакетной скидкой,
подбор нестандартной локации под запрос клиента.

## Проблема
Заявки на съёмку сейчас приходят вперемешку в Instagram-директ и
WhatsApp/Telegram — ≈6–10 запросов в неделю, часть переписки теряется
между каналами.

# Съёмка.kz

Платформа бронирования локаций и съёмочной команды (фото/видео) в Астане.

## О проекте

**Съёмка.kz** — веб-платформа для бронирования локаций и съёмочной команды
в Астане, объединяющая в одном месте выбор площадки и подбор специалиста
для фото- и видеосъёмки.

Идея выросла из реальной практики: Арсен — практикующий мобилограф,
работающий совместно со студией из трёх человек. Сейчас заявки ведутся
вручную и разрозненно — часть в Instagram-директе, часть в
WhatsApp/Telegram, без единого места, где видно все запросы, их статус
и историю переписки.

## Проблема

≈6–10 запросов на съёмку в неделю по двум разным каналам. Часть
переписки теряется между чатами, приходится вручную сверять свободные
слоты в нескольких местах, нет единого каталога цен и условий.

## Как это устроено

В основе — **локация как центральный объект бронирования**, а не
человек-исполнитель.

- **5 готовых локаций студии** — у каждой свой характер (лофт, циклорама-зал,
  крыша, зимний сад, ангар), с фото- и видеопримерами прошлых съёмок
- **Подбор нестандартной локации** — если ничего из каталога не подходит,
  клиент оставляет запрос под свои условия
- **Съёмочная команда как опция** — фотограф/видеограф/мобилограф можно
  добавить к брони отдельно, если своей команды нет; если своя есть —
  просто арендуется локация
- **Пакетная скидка** — при бронировании локации и команды вместе

## Ценность

Клиенту не нужно вести переговоры в переписке, чтобы узнать, что вообще
доступно — цены, примеры, свободные слоты видны сразу на сайте. Студии —
меньше ручной координации и меньше риска потерять заявку между каналами.

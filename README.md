# Съёмка.kz — MVP бронирования локаций

Сервис выбора и бронирования съёмочных локаций в Астане. Клиент выбирает площадку, дату и свободное время, оставляет заявку; администратор управляет заявками. Локально приложение сохраняет данные в SQLite. Для размещения на Render предусмотрен PostgreSQL в Neon через `DATABASE_URL`.

## Быстрый запуск

Нужен **Node.js 24 или новее** с npm. Проверьте версии:

```sh
node --version
npm --version
```

В терминале в папке репозитория выполните:

```sh
npm install
npm run setup
npm run dev
```

Откройте **http://localhost:5173**. Команда `dev` одновременно запускает Vite и API. Остановить оба процесса можно через `Ctrl+C` в том же терминале. Отдельные окна терминала не открываются.

Для установки точно зафиксированных в `package-lock.json` версий можно использовать `npm ci` вместо `npm install`. В локальном режиме с SQLite после установки постоянное подключение к интернету не требуется. При подключении к Neon интернет нужен для запросов к базе.

`npm run setup` создаёт `.env` со случайным паролем администратора и показывает его в терминале. Если `.env` уже существует, команда оставляет его без изменений. Чтобы посмотреть пароль позже, откройте `.env`: значение находится после `ADMIN_PASSWORD=`. Не отправляйте этот файл и пароль в репозиторий или переписку.

В Windows PowerShell, если запуск `npm.ps1` запрещён политикой компьютера, используйте `npm.cmd` вместо `npm`; менять политику PowerShell не требуется.

## Что работает

- Каталог пяти демонстрационных площадок: лофт, циклорама, крыша, зимний сад и ангар.
- Выбор площадки, даты и времени; расчёт стоимости по длительности аренды.
- Создание заявки и проверка пересечения бронирований на сервере.
- Ссылка для проверки статуса заявки без регистрации.
- Просмотр заявок, изменение статусов и блокировка времени через административную страницу.
- Сохранение данных после перезапуска сервера.

Названия, описания, цены, доступность и другие данные каталога подготовлены для демонстрации. Они не подтверждают реальные условия аренды или существование доступного для заказа предложения.

Источники иллюстраций и условия их использования указаны в [списке фотографий](docs/image-credits.md).

Подбор фотографа или съёмочной команды, пакетные скидки, индивидуальный поиск площадки, платежи, SMS и внешние уведомления в этот MVP не входят. Первоначальная идея проекта сохраняется в [описании границ MVP](docs/mvp-scope.md).

## Администратор и бронирование

Откройте **http://localhost:5173/admin** и введите пароль из `.env`. Отдельное имя пользователя не требуется. Для демонстрации используйте вымышленные контактные данные. После работы завершите административную сессию через кнопку выхода.

Время аренды — с 09:00 до 21:00 по Астане, с шагом один час. Можно выбрать длительность от одного до восьми часов и дату в пределах ближайших 90 дней. Заявка сначала получает статус ожидания и временно занимает интервал на два рабочих часа в рамках 09:00–21:00. Администратор подтверждает, отклоняет или отменяет её. Неподтверждённая заявка истекает по окончании этого срока. Оплата в приложении не принимается.

## Локальная сборка без Vite

```sh
npm run build
npm start
```

Откройте **http://localhost:3001**. API отдаёт собранный интерфейс из `dist/`. Перед `npm start` остановите `npm run dev`, чтобы освободить порт 3001. Это локальный режим проверки собранного приложения, а не настройка публичного сервера.

## Настройки и данные

| Настройка | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3001` | Порт API и собранного сайта |
| `HOST` | `127.0.0.1` локально | На Render задайте `0.0.0.0` |
| `NODE_ENV` | Не задан | На Render — `production` |
| `ADMIN_PASSWORD` | Генерируется при `setup` | Пароль администратора, от 12 до 256 символов |
| `DATABASE_URL` | Не задан | Строка подключения PostgreSQL; при наличии выбирается PostgreSQL |
| `DB_PATH` | `data/semka.sqlite` | Путь к SQLite, используется только без `DATABASE_URL` |
| `ALLOWED_ORIGIN` | На Render берётся `RENDER_EXTERNAL_URL` | Точный HTTPS-адрес сайта; вручную нужен для своего домена или другого хостинга |

Локально сервер слушает `127.0.0.1`. Для первого запуска оставьте порты по умолчанию: 5173 для Vite, 3001 для API. Если меняете порт API, обновите также адрес прокси `/api` в `vite.config.js`. Настройки перечислены в [.env.example](.env.example); копировать пример вместо `npm run setup` не нужно.

Без `DATABASE_URL` база и служебные файлы SQLite создаются в `data/`. Они, `.env`, зависимости и сборка исключены из Git. Не удаляйте `data/`, если хотите сохранить локальные заявки. При заданном `DATABASE_URL` приложение использует PostgreSQL и не требует SQLite-файла. В режиме `NODE_ENV=production` запуск без PostgreSQL запрещён, чтобы заявки не оказались на временном диске хостинга.

Для резервной копии остановите приложение и скопируйте **всю папку `data/`** в безопасное место. Пароль при необходимости сохраните отдельно. Для восстановления при остановленном приложении верните сохранённую папку `data/`. Копирование только одного файла работающей SQLite может пропустить данные из журнала WAL.

Эта файловая копия относится только к SQLite. PostgreSQL в Neon — отдельная база: локальные заявки автоматически в неё не переносятся. При первом подключении приложение создаёт таблицы, а демонстрационный каталог берётся из кода. Для PostgreSQL используйте отдельные резервные копии и доступные в вашем плане средства восстановления Neon.

## Размещение на Render и Neon

[Пошаговая инструкция](docs/deploy-render-neon.md) описывает Render Web Service Free и Neon Free: Node.js 24, один сервис для интерфейса и API, отдельная PostgreSQL-база. Собственный домен не требуется — Render предоставляет HTTPS-адрес `onrender.com`.

[Развернуть через Render Blueprint](https://render.com/deploy?repo=https://github.com/AASSAA17/-.kz) — конфигурация находится в [render.yaml](render.yaml). Сначала создайте Neon-проект и подготовьте `DATABASE_URL`: Render запросит эту строку, а пароль администратора создаст автоматически. Его можно посмотреть в Environment созданного сервиса.

Стоимость — $0 при использовании бесплатных планов в их лимитах. Render Free засыпает после 15 минут без входящих запросов; первый ответ после простоя может задержаться примерно на минуту. Данные Neon сохраняются независимо от перезапусков Render. Эти ограничения и условия оплаты проверены по официальным источникам и приведены в инструкции. Здесь описана конфигурация размещения; наличие файла инструкции само по себе не означает, что сайт уже опубликован.

## Технологии

| Слой | Реализация MVP |
| --- | --- |
| Интерфейс | React, Vite |
| API | Node.js 24, `node:http` |
| Хранение локально | SQLite, встроенный модуль `node:sqlite` |
| Хранение на хостинге | PostgreSQL в Neon, драйвер `pg` |
| Запуск | npm; локальный Node.js или Render Native Node |

Для локального режима с SQLite отдельный сервер базы данных, Docker и облачные аккаунты не нужны. Для размещения по инструкции потребуются аккаунты Render и Neon. Браузер обращается только к API приложения; строка подключения к базе остаётся на сервере.

## Границы применения

MVP предназначен для проверки сценариев и учебной демонстрации локально или на бесплатном хостинге. HTTPS и параметры production предусмотрены инструкцией размещения. Перед работой с настоящими клиентами нужны отдельные проверки защиты и нагрузки, управление пользователями и правами, резервное копирование, мониторинг и согласованные правила работы с персональными данными. Подробности и незакрытые ограничения перечислены в технической заметке.
